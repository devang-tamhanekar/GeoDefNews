The system addresses the challenge of information overload by securely 
fetching and curating content from a whitelisted network of external RSS feeds. It offers a 
responsive front-end for filtering news by regions and includes a contact form for user 
communication. A core objective of the project is to implement robust security protocols, 
including password hashing and protection against vulnerabilities like CSRF and SSRF, and 
to provide a secure administrative dashboard for message management.

Tools and Technologies:
 Front End: The front-end tools include HTML5, CSS3, and Bootstrap 5.3.
 Back End: The back-end is powered by PHP 8.0+.
 Database: The database used is MySQL.
 Server: The web server is Apache.
 APIs/Feeds: External RSS Feeds are utilized for news aggregation.

# How to Run Locally
1. Install XAMPP (or any PHP + MySQL setup)
2. Copy the project folder into `htdocs`
3. Import `database.sql` into phpMyAdmin
4. Copy `config.example.php` to `config.php` and add your own database details
5. Open `http://localhost/GeoDefNews`
